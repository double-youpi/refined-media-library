# Security policy

## Supported versions

Only the latest release published on [WordPress.org](https://wordpress.org/plugins/doubleyoupi-refined-media-library/) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue or pull request.

Report it privately with GitHub's **"Report a vulnerability"** button, in the Security tab of this repository.

Please include the plugin version, the steps to reproduce, and the impact you observed. You will get an answer within 72 hours, and a fix is released as soon as it is ready. With your permission, you will be credited in the changelog.
