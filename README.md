# Double Youpï Refined Media Library

Double Youpï Refined Media Library (RML) is a free WordPress plugin, with no Pro version, that adds folders and collections to the WordPress media library, with duplicate and unused media cleanup and WebP or AVIF copies on upload.

[![Try it live (no install)](https://img.shields.io/badge/Try_it_live-no_install-5b3efe?style=for-the-badge&logo=wordpress&logoColor=white)](https://wordpress.org/plugins/doubleyoupi-refined-media-library/?preview=1) [![Install from WordPress.org](https://img.shields.io/badge/Install_from-WordPress.org-3858e9?style=for-the-badge&logo=wordpress&logoColor=white)](https://wordpress.org/plugins/doubleyoupi-refined-media-library/)

The live preview opens the plugin in WordPress Playground, in your browser: nothing to install, nothing kept.

## What it does

- **Folders that feel like folders.** Real nested folders, drag to re-parent or reorder, right-click menus, and uploads straight into the folder you are looking at.
- **Collections** that ignore folder boundaries, so one image can sit in several at once.
- **A real detail panel** beside the grid: alt text, title, folder, collections, URL, and exactly which posts and pages use the file.
- **Less clutter, automatically.** Alt text and titles filled from the filename when blank, duplicate detection on upload, and an unused-media scanner that errs on the side of caution: if it cannot be sure a file is unused, it leaves it alone.
- **WebP and AVIF on upload**, after checking that your server can do it. It steps aside if another plugin already converts images.
- **One-click import** from FileBird, Real Media Library, HappyFiles, Folders (Premio) and Enhanced Media Library. Their data is never touched, and the import can be undone.

It works on top of the native media library, so it behaves the same with Bricks, Elementor, Gutenberg or Divi. No per-image settings, no Pro version, nothing held back.

It is also bundled whole in [Double Youpï Refined Admin Dashboard](https://wordpress.org/plugins/doubleyoupi-refined-admin-dashboard/), which redraws the rest of the admin in the same style.

**Requirements:** WordPress 6.5 or later, PHP 8.1 or later.

## About this repository

This repository mirrors **every release published on WordPress.org**. Each commit is one release, tagged with its version number, and the files are exactly those of the WordPress.org package. The SCSS sources of the stylesheets are added under `assets/scss/`.

Development happens in a private repository that also holds other projects. This one starts with the first release published on WordPress.org: each release is a tagged commit, dated the day it went out (the README may be updated in between). For the earliest releases, the SCSS sources are no longer available.
